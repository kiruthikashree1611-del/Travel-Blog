Travel Blog Page

 Project Overview

The Travel Blog Page is a responsive website developed using HTML5 and CSS3. It is designed to showcase travel experiences, beautiful destinations, and a photo gallery in an attractive and organized layout. The webpage also includes a contact form, allowing visitors to connect with the blog owner.

 Features

- Travel blog posts with destination descriptions
- Responsive photo gallery using CSS Grid
- Contact form for visitor messages
- Hover effects on images and buttons
- Responsive design for mobile, tablet, and desktop
- Clean and modern user interface

 Technologies Used

- HTML5
- CSS3

 Project Structure

Travel-Blog/
│── travelblog.html
└── README.md

 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open travelblog.html in any modern web browser (Chrome, Edge, Firefox, etc.).
4. Explore the travel stories, image gallery, and contact form.

 Learning Outcomes

- Learned to structure web pages using semantic HTML elements.
- Built responsive layouts using CSS Grid.
- Applied CSS styling, hover effects, and responsive design.
- Improved webpage organization and user interface design skills.
